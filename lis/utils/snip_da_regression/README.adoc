= Noah-MP 5.0 SNIP regression test

Standalone check of the SNIP snow-state updater using the shared snow physics.

== Usage

Run with a configured Fortran compiler:

[source,bash]
----
FC=ifx python3 lis/utils/snip_da_regression/run_tests.py --output snip-unit-results
----

`FC` selects the compiler; `FFLAGS` may override the compiler flags.
The output directory must not already exist.

== Checks

Compares non-reduction updates with the existing Noah-MP 5.0 USAFSI updater
and checks snow depth/SWE reductions, including zero targets and layer consistency.
Success prints `SNIP_UNIT_PASS 147 58`.
